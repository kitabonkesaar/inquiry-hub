# RentAnyBus - Commercial Fleet & Bus Rental Platform

Premier specialized bus rental and commercial coach charter platform for Odisha and Eastern India, catering to Tirth Yatra tours, Corporate travel, and Educational picnics.

## Tech Stack

- **Framework**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **Backend / Database**: Supabase PostgreSQL
- **Icons**: Lucide React
- **Notifications**: Sonner

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```

## Features

- **Fleet Marketplace**: Explore buses and tempo travellers with 16:9 galleries, amenities, and layout specs.
- **Seat Layout Visualizer**: Visual cabin layouts for 2x2 Sleepers, 3x2 Seaters, and luxury lounges.
- **Quick Quote System**: Direct customer inquiry system with rapid callbacks.
- **Admin Dashboard**: Comprehensive fleet management, inquiries, blog posts, and settings.
